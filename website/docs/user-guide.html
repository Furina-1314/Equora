衡序 Equora 用户指南

版本 1.0.2 正式版 · 适用 Windows 10 19041+ / Windows 11（x64）

1. 快速开始

1.1 安装

从 最新正式版 下载 EXE 安装包（推荐）或 MSIX。EXE 使用原目录即可升级；MSIX 首次安装需信任随附证书。两种安装包均包含运行时。首次启动自动创建本地数据库:

%LOCALAPPDATA%\Equora\equora.db

无需账号、无需联网,安装后即可完整使用全部核心功能。

1.2 三分钟上手

  1. 收集:按 Ctrl+Shift+Space 打开快速输入,输入「明天下午3点开会一小时 #工作 !高」回车。识别结果预览确认后自动创建任务并设置截止时间、标签和优先级。
  2. 整理:在任务页用智能清单(收集箱/今天/逾期/无日期)过滤,选中任务后在右侧详情栏编辑。
  3. 排程:把左侧「未安排任务」拖入日历周视图,自动创建时间块。
  4. 专注:在任务上启动专注（番茄钟、深度工作或正计时），计时中按 Ctrl+Shift+Space 记录分心想法。
  5. 回顾:专注结束后看到今日累计时长与休息建议。

2. 核心功能

2.1 任务管理(三栏)

左栏 中栏 右栏
9 个智能清单
项目列表
标签列表		 搜索框 + 任务列表
(完成/删除/恢复)		 详情编辑

截止/时长/标签/检查项)
  • 智能清单:收集箱、今天、近期 7 天、已逾期、无日期、等待中、已完成、全部、回收站
  • 搜索:标题与备注子串匹配,大小写不敏感
  • 撤销:任务页支持撤销部分操作（上限 100 步）；回收站条目可恢复。永久删除和批量删除日程无法撤销。
  • 快捷键:Ctrl+N 新建任务 · Ctrl+K 命令面板 · Ctrl+Shift+Space 快速收集

2.2 日历与时间块

  • 周/日视图:拖拽空白创建、拖动移动、底部手柄缩放(15 分钟吸附)
  • 当前时间线(红色横线,每分钟刷新)
  • 工作时间底纹(工作日 09:00–18:00)
  • 冲突检测:重叠时间块红描边,侧栏可查看冲突对详情
  • 重复规则:支持每周 X / 每天 / 每月第 N 个星期 X / 最后一个星期 X
  • ICS 导入导出:日历页选择文件位置后操作。导入的日程可右键编辑或删除；重复日程的右键菜单明确提供整个系列的编辑、删除。

2.2.1 学期模式与批量安排

在设置中开启学期模式，设置学期名和起止日期。每周按周一至周日计算，起始日期所在周为第 1 周。日历可按每周或指定周次（如 1,3,5-8）添加日程，仅生成学期日期范围内的安排。

创建时可勾选“同时添加到任务列表”；不勾选时仅创建日历日程，同样支持标题、备注、颜色和独立编辑；颜色输入框右侧的方块实时预览色号,点击可打开选色表。右键进入批量编辑或批量删除，同一批次跨周列出，复选框打勾选择要处理的条目和字段；批量编辑保留各自日期，可同步关联任务标题。删除可选择同时将关联任务移入回收站。

旧版安排没有批次标识，需手动勾选，不会自动按同名标题分组。学期结束日期次日起自动归档；在设置的“以往学期”中查看历史，再设置新学期。归档或关闭模式均不删除原有任务和日程。

2.2.2 清空本机数据

“设置 → 数据与备份 → 清空数据…”需要三次确认，最后输入“清空数据”。任何一步取消均不执行。确认后停止写入、关闭数据库，将当前数据移到 backups/before-reset-* 恢复副本并退出，下次启动建立空白工作空间。已有备份、日志、其他文件及远端同步数据保留。正在专注时请先结束专注。

2.3 四象限

  • 可解释归类:重要 = 重要性 ≥ 3,紧急 = 3 天内截止
  • 拖拽换象限自动调整重要性/截止时间(全部可撤销)
  • 今日三件要事:从 Q1/Q2 双击设为要事(上限 3 件)
  • 容量提示:各象限计数与估时合计

2.5 专注会话

模式 说明
番茄钟 25 分钟 + 5 分钟休息(可自定义)
深度工作 60–120 分钟长块
正计时 向上累计
  • 关联任务开始/结束时自动流转任务状态
  • 分心捕获:专注中按 Ctrl+Shift+Space 记录,不切焦点;结束后一键转任务
  • 崩溃恢复:软件崩溃后重启自动收尾未闭合会话
  • 前台应用温和提醒(默认关闭):在分心应用窗口顶部显示醒目提醒，仅识别进程名(如 game.exe),不采集窗口内容

2.6 网站限制(浏览器扩展)

  • 根据专注、指定时段和每日额度限制网站，包含规则域名的子域名。
  • 扩展连接桌面应用并根据有效心跳更新限制；桌面端退出或心跳超时后自动解除。
  • 封锁页提供“关闭此页面”和“临时允许 5 分钟”，允许到期后恢复限制；该机会不会因刷新或重启浏览器重置。
  • 有每日额度的网站会在网页右上角显示剩余时间，至少 10 分钟精确到分钟，低于 10 分钟精确到秒。受限进程也显示封锁页，每个应用可临时允许一次、共 5 分钟，重启不会重置。
  • 详细连接步骤与行为见应用与网站限制。

3. 数据安全

3.1 你的数据在哪里

所有数据存储在本地 %LOCALAPPDATA%\Equora\:

文件 说明
equora.db 主数据库(SQLite,WAL 模式)
backups/ 自动/手动备份(带 SHA-256 校验)
logs/equora.log 运行日志(脱敏,不含任务正文)

3.2 备份与恢复

  • 设置页「立即备份」:创建一致性快照(在线,不需要关闭软件)
  • 每个备份带校验和,恢复前自动验证
  • 恢复前自动保护当前数据库(.pre-restore 快照)

3.3 导出

  • JSON:任务全字段(幂等导入,按 ID 跳过已存在)
  • CSV:Excel 兼容(UTF-8 BOM,中文可直接打开)
  • ICS:日历标准格式(事件 + 时间块)

3.4 隐私边界

绝不采集 说明
键盘输入 不做键盘记录
屏幕截图 不截屏
窗口标题/内容 仅进程名(xxx.exe),且默认关闭
剪贴板内容 不读取
浏览历史 仅匹配域名,不记录页面

4. 多设备同步(可选)

同步默认关闭。启用后:

  1. 部署同步服务器(Docker Compose,见 server/README.md)
  2. 设置页填入服务器地址与令牌
  3. 软件在后台自动推送/拉取(指数退避重试)

冲突处理:并发修改同一任务时,后到方自动进入「冲突中心」,可查看双方版本并选择保留本地/采纳服务端/手动合并。删除与修改冲突默认保留删除(可恢复)。

5. 常见问题

Q: 软件崩溃后会话丢失吗?
A: 不会。专注会话和分心记录在每一步都立即写入数据库;重启后自动收尾。

Q: 备份文件可以复制到另一台电脑用吗?
A: 可以。备份是完整 SQLite 快照,复制到新机器后在设置页恢复即可。

Q: 网站限制会永久阻断我吗?
A: 不会永久阻断。限制可由专注、指定时段或每日额度触发；桌面端退出或心跳过期后自动解除。每个网站可临时允许 5 分钟，但刷新或重启浏览器不会重置该机会。详见应用与网站限制。

Q: 忘记了紧急解锁怎么办?
A: 紧急解锁冷却 15 分钟,过期后可再次触发。所有限制都以「宁可放开不可锁死」为设计原则。
