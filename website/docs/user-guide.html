衡序 Equora 用户指南

版本 0.1.0 · 适用 Windows 10 1809+ / Windows 11

1. 快速开始

1.1 安装

下载 MSIX 安装包(或解压版),双击安装。首次启动自动创建本地数据库:

%LOCALAPPDATA%\Equora\equora.db

无需账号、无需联网,安装后即可完整使用全部核心功能。

1.2 三分钟上手

  1. 收集:按 Ctrl+Shift+Space 打开快速输入,输入「明天下午3点开会一小时 #工作 !高」回车。识别结果预览确认后自动创建任务并设置截止时间、标签和优先级。
  2. 整理:在任务页用智能清单(收集箱/今天/逾期/无日期)过滤,选中任务后在右侧详情栏编辑。
  3. 排程:把左侧「未安排任务」拖入日历周视图,自动创建时间块。
  4. 专注:在任务上启动专注(番茄钟/深度/Flowtime),计时中按 Ctrl+Shift+Space 记录分心想法——不打断当前焦点。
  5. 回顾:专注结束后看到今日累计时长与休息建议。

2. 核心功能

2.1 任务管理(三栏)

左栏 中栏 右栏
9 个智能清单
项目列表
标签列表		 搜索框 + 任务列表
(完成/删除/恢复)		 详情编辑
(标题/备注/状态/优先级/
截止/时长/标签/检查项)
  • 智能清单:收集箱、今天、近期 7 天、已逾期、无日期、等待中、已完成、全部、回收站
  • 搜索:标题与备注子串匹配,大小写不敏感
  • 撤销:所有操作可撤销(上限 100 步);回收站条目可恢复
  • 快捷键:Ctrl+N 新建任务 · Ctrl+K 命令面板 · Ctrl+Shift+Space 快速收集

2.2 日历与时间块

  • 周/日视图:拖拽空白创建、拖动移动、底部手柄缩放(15 分钟吸附)
  • 当前时间线(红色横线,每分钟刷新)
  • 工作时间底纹(工作日 09:00–18:00)
  • 冲突检测:重叠时间块红描边,侧栏可查看冲突对详情
  • 重复规则:支持每周 X / 每天 / 每月第 N 个星期 X / 最后一个星期 X
  • ICS 导入导出:设置页一键操作

2.3 四象限

  • 可解释归类:重要 = 重要性 ≥ 3,紧急 = 3 天内截止
  • 拖拽换象限自动调整重要性/截止时间(全部可撤销)
  • 今日三件要事:从 Q1/Q2 双击设为要事(上限 3 件)
  • 容量提示:各象限计数与估时合计

2.4 快速收集(自然语言)

输入示例 识别结果
明天下午3点开会一小时 截止=明天 15:00,估时=60 分钟
每周五17点提醒写周报 截止=本周五 17:00,重复=每周五
下周三前完成设计稿 #产品 !高 截止=下周三,标签=产品,优先级=高
今晚安排45分钟复习电路 截止=今晚,估时=45 分钟
和 @设计 组对齐 14:30 项目=设计,截止=14:30

识别不出的内容保留为标题,绝不丢弃。

2.5 专注会话

模式 说明
番茄钟 25 分钟 + 5 分钟休息(可自定义)
深度工作 60–120 分钟长块
Flowtime 自由计时,完成时记录实际时长
正计时 向上累计
无计时 沉浸模式,不看时间
  • 关联任务开始/结束时自动流转任务状态
  • 分心捕获:专注中按 Ctrl+Shift+Space 记录,不切焦点;结束后一键转任务
  • 崩溃恢复:软件崩溃后重启自动收尾未闭合会话
  • 前台应用温和提醒(默认关闭):仅识别进程名(如 game.exe),不采集窗口内容

2.6 网站限制(浏览器扩展)

  • 专注期间按桌面端下发的名单温和限制网站
  • 扩展不持久化规则 → 浏览器重启/扩展异常后自动解除,绝不永久阻断
  • 拦截页提供「返回任务」和「允许 5 分钟」
  • 白名单域名优先于限制名单

3. 数据安全

3.1 你的数据在哪里

所有数据存储在本地 %LOCALAPPDATA%\Equora\:

文件 说明
equora.db 主数据库(SQLite,WAL 模式)
backups/ 自动/手动备份(带 SHA-256 校验)
logs/equora.log 运行日志(脱敏,不含任务正文)

3.2 备份与恢复

  • 设置页「立即备份」:创建一致性快照(在线,不需要关闭软件)
  • 每个备份带校验和,恢复前自动验证
  • 恢复前自动保护当前数据库(.pre-restore 快照)

3.3 导出

  • JSON:任务全字段(幂等导入,按 ID 跳过已存在)
  • CSV:Excel 兼容(UTF-8 BOM,中文可直接打开)
  • ICS:日历标准格式(事件 + 时间块)

3.4 隐私边界

绝不采集 说明
键盘输入 不做键盘记录
屏幕截图 不截屏
窗口标题/内容 仅进程名(xxx.exe),且默认关闭
剪贴板内容 不读取
浏览历史 仅匹配域名,不记录页面

4. 多设备同步(可选)

同步默认关闭。启用后:

  1. 部署同步服务器(Docker Compose,见 server/README.md)
  2. 设置页填入服务器地址与令牌
  3. 软件在后台自动推送/拉取(指数退避重试)

冲突处理:并发修改同一任务时,后到方自动进入「冲突中心」,可查看双方版本并选择保留本地/采纳服务端/手动合并。删除与修改冲突默认保留删除(可恢复)。

5. 常见问题

Q: 软件崩溃后会话丢失吗?
A: 不会。专注会话和分心记录在每一步都立即写入数据库;重启后自动收尾。

Q: 备份文件可以复制到另一台电脑用吗?
A: 可以。备份是完整 SQLite 快照,复制到新机器后在设置页恢复即可。

Q: 网站限制会永久阻断我吗?
A: 不会。限制只在专注会话期间生效,使用浏览器会话规则(重启即清空)。即使桌面端异常,浏览器重启后所有限制自动解除。

Q: 忘记了紧急解锁怎么办?
A: 紧急解锁冷却 15 分钟,过期后可再次触发。所有限制都以「宁可放开不可锁死」为设计原则。
