帮助中心 / 使用帮助与快捷键

Equora 使用帮助

快捷键

快捷键 操作
Ctrl+N 新建任务
Ctrl+K 打开命令面板
Ctrl+Shift+空格 打开快速记录
Ctrl+Z 在任务页撤销上一步支持撤销的操作

以上快捷键在 Equora 窗口内生效。所有悬停说明已移除，可在“设置 → 使用帮助与快捷键”查看。

日历

点击日历空白时间格，或在空白处拖出时间范围，可快速新建时间段并选择是否同时创建任务。左侧“新建时间段”默认仅安排时间，可填写独立标题、备注、开始日期和时间、结束日期和时间以及颜色。时间范围允许跨天；结束时间必须晚于开始时间。

右键时间段可编辑或删除。删除时间安排保留关联任务。已有任务也可从左侧拖入日历。

右键还支持“批量编辑时间段”和“批量删除时间段”。新建学期批次会跨周列出同批次安排；旧版无批次标识时需手动选择。批量编辑只改变勾选字段；可选择同步关联任务标题，删除时也可选择将关联任务移入回收站。

学期模式与归档

在设置页“数据与备份”后开启学期模式，填写学期名、起止日期。每周从周一开始，起始日期所在周为第 1 周。日历支持每周或特定周次（例如 1,3,5-8）添加相同时间安排；取消勾选“同时添加到任务列表”即可只生成日历时间段。

结束日期次日自动归档，旧任务和时间段保留。在“以往学期”选择学期即可打开历史日历，再填写新学期继续使用。关闭模式需要二次确认。

清空数据

设置页“数据与备份”中的“清空数据…”需要三次确认，最后输入“清空数据”。取消任何一步均不执行。程序会保留 backups/before-reset-* 恢复副本后退出，下次启动为空白工作空间；已有备份、日志及其他文件保留。清空仅作用于本机，远端同步数据不删除。正在专注时需先结束专注。

日历的“导出 ICS”会打开保存位置选择框；设置中的 JSON、CSV 导出和备份同样可选择位置，取消选择不会执行导出。

后台运行

在“设置 → 启动与关闭”选择关闭窗口时退出程序，或隐藏到托盘。托盘图标单击恢复窗口，右键退出；再次启动 Equora 也会恢复已有窗口。关闭到托盘后专注计时、轮次切换、应用和网站限制继续工作；退出进程后不再工作。

可通过同一区域的开关设置登录 Windows 时自启动。该设置只在操作开关时变更，不会自动启用。

专注模式

  • 番茄钟：设定每轮专注时长、1–20 轮和 1–60 分钟轮间休息。专注结束后自动进入休息，休息结束后开始下一轮，最后一轮完成后停止。休息不计入专注时长，也不触发“专注时限制”。暂停可冻结工作或休息计时；结束会停止整组番茄钟。
  • 深度工作：单次倒计时，到时结束，不自动进入休息或下一轮。
  • 正计时：从零累计有效专注时间，由使用者手动结束。

移除了与上述模式重复的 Flowtime 和无计时入口，历史记录仍保留。轮数和休息时长自动保存。

数据目录

“设置 → 更改数据目录”选择当前数据目录以外的空文件夹。确认后复制一致的数据库快照、设置、限制记录和已有备份，成功后退出；下次启动使用新目录。原文件保留，失败时继续使用原目录。迁移前需结束专注，旧日志保留在原目录。

数据目录定位文件位于 %LOCALAPPDATA%\Equora\data-location.txt，请保持目标目录可用，避免移除正在使用的外置磁盘。浏览器连接组件会随定位文件读取新的数据目录。

隐私与应用限制

原设置页的“隐私与专注”已移到“使用限制 → 隐私与分心提醒”。提醒只提示分心行为；限制规则会最小化受限窗口。两者均只识别进程名，不读取窗口正文或键盘输入。

网站扩展的安装和连接见 应用与网站限制。
