Equora 隐私与安全说明

版本 1.0.0 · 最后更新:2026-09-23

1. 隐私承诺

Equora 是本地优先软件。你的任务、时间块、专注记录、统计数据默认只存在于你自己的电脑上,不上传、不遥测、不分析。

2. 数据采集清单

2.1 默认采集(本地)

数据 用途 存储位置 可删除
任务/项目/标签内容 核心功能 本地 SQLite ✅ 单条删除/清空
时间块与日历事件 排程功能 本地 SQLite ✅
专注会话记录 统计与复盘 本地 SQLite ✅
分心捕获内容 你的临时笔记 本地 SQLite ✅ 整理后删除
运行日志(脱敏) 故障排查 logs/equora.log ✅ 删除文件

2.2 明确不采集

以下数据永远不采集,无论设置如何:

  • ❌ 键盘输入内容
  • ❌ 屏幕截图
  • ❌ 窗口标题或页面内容
  • ❌ 剪贴板内容
  • ❌ 完整浏览历史
  • ❌ 密码或认证信息
  • ❌ 联系人或通讯录

2.3 可选采集(默认关闭)

数据 条件 内容 关闭后
前台应用进程名 用户在设置页主动开启 仅 xxx.exe 格式进程名 立即停止检测,无残留

前台应用监测的工作方式:通过 Windows API 监听前台窗口变化事件,获取当前进程名(如 game.exe),与受限名单比对。不读取窗口标题、不读取页面内容、不记录浏览历史。 关闭后立即停止全部检测。

3. 网络通信

3.1 默认状态:零网络

同步功能默认关闭。关闭状态下软件不发起任何网络请求。

3.2 启用同步后

如果你主动启用多设备同步:

  • 仅与你自己配置的服务器通信(HTTPS)
  • 传输内容:任务/时间块/专注记录(已加密传输)
  • 服务器地址与令牌存储在本地,不上传到任何第三方
  • 浏览器扩展通过 Native Messaging(本机管道)与桌面端通信,不经过互联网

3.3 浏览器扩展

  • 扩展仅获取域名(如 example.com)用于匹配限制名单
  • 不读取页面内容、不记录浏览历史
  • 限制规则只在专注期间生效,使用会话规则(浏览器重启自动清空)
  • 扩展权限最小化:declarativeNetRequest(网络请求拦截)+ nativeMessaging(本机通信)+ storage(本地预算存储)+ tabs(获取当前标签域名)

4. 数据安全

4.1 本地数据保护

  • 数据库存储在用户私有目录(%LOCALAPPDATA%\Equora\),受 Windows 用户账户权限保护
  • 备份带 SHA-256 校验,恢复前验证完整性
  • 恢复前自动保护当前数据(防误操作)

4.2 传输安全(同步启用时)

  • 客户端仅通过 HTTPS 与服务器通信
  • 认证令牌仅在内存和 Windows 安全存储中,不写入源码或日志
  • 服务器端令牌仅存 SHA-256 哈希,不存明文

4.3 限制系统的安全出口

所有应用/网站限制必须提供:

  1. 安全白名单:系统设置、安全软件、文件管理器、辅助功能、紧急通信、恢复工具、Equora 自身——这 20+ 关键进程永不被限制,无论配置如何
  2. 紧急解锁:一键解除全部限制(15 分钟冷却)
  3. 自动解除:浏览器重启/扩展异常/桌面端崩溃后所有限制自动解除
  4. 设计原则:宁可放开不可锁死(网络故障时规则撤销而非加强)

5. 数据可携带性

导出格式 覆盖范围
JSON 任务全字段(幂等导入)
CSV 任务(Excel 兼容)
ICS 日历事件与时间块
SQLite 备份 完整数据库快照

6. 数据删除

  • 单条:在界面中删除(软删除,回收站可恢复)
  • 全部任务:清空回收站
  • 全部数据:删除 %LOCALAPPDATA%\Equora\ 目录
  • 活动分析:设置页关闭后立即停止,已记录数据随任务删除

v1.0.0 本机数据重置

清空数据需要三次确认，最后输入“清空数据”。清空任务、日历、专注及设置前，程序关闭数据库，将已知数据文件移至 backups/before-reset-*。已有备份、日志、其他文件、浏览器扩展本身的本地存储和远端同步数据不受影响。因此该操作用于重置工作空间，并不是不可恢复的安全擦除。退出程序后可将恢复副本复制回原数据目录。
