# Equora v0.2.2 — 学期模式

新增学期设置与按周批量安排任务，适合课程、每周自习和固定活动。

- 设置页“数据与备份”之后新增“学期模式”，开启后可设置学期名、起始日期和结束日期。
- 起始日期所在周为第 1 周，每周按周一至周日计算；设置页显示当前周次，日历页显示正在查看的学期周次。
- 日历新增“按学期批量添加”，可选择每周或特定周次（例如 `1,3,5-8`）、星期和起止时间，并设置任务标题、备注和颜色。
- 添加前显示预计生成数量和日期范围；仅在学期起止日期范围内生成时间段。
- 每项生成独立任务和时间段，可分别编辑。修改学期设置或关闭学期模式不会改变已添加内容。
- 关闭学期模式需要二次确认，取消不会关闭；关闭后保留学期设置，便于再次开启。
- 扩展配置面板标题更新为与桌面应用一致的 EQUORA 字标；网站封锁页信息框右下角新增同款字标。

## 安装与升级

- `Equora-v0.2.2-win-x64-Setup.exe`：推荐，使用原安装目录即可升级，无需单独安装 .NET。
- `Equora-v0.2.2-win-x64.msix`：版本号为 0.2.2.0，沿用原包标识和签名证书。
- `Equora-v0.2.2.cer`：MSIX 首次安装使用的公钥证书；已信任旧版证书无需重复导入。EXE 无需导入证书。
- `Equora-v0.2.2-BrowserExtension.zip`：随版本提供的网站限制扩展。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

已有任务和数据自动沿用，学期模式默认关闭。安装包使用自签名证书，Windows 可能显示发行者信任提示。

本版本附件已合并扩展外观更新。已安装 v0.2.2 的用户可重新下载扩展 ZIP，覆盖原加载目录并在浏览器扩展管理页重新加载，即可更新字标外观；保持原目录可保留扩展 ID。
