# Equora v0.2.1

本次更新修复浏览器临时允许功能，并完善暂停限制提示和回收站操作。

- 修复带路径、端口、查询参数的网站点击“临时允许 5 分钟”时误报“网站地址无效”；兼容旧拦截页。
- 扩展提供连接状态面板、复制扩展 ID、网页右上角倒计时；临时允许到期后恢复拦截并禁止重复领取。
- 点击“暂停所有限制 15 分钟”后，应用顶部显示黄色警告及倒计时，切换页面仍可见；到期自动隐藏，恢复限制状态。
- 回收站支持永久删除。任务删除及永久删除均要求二次确认，取消不会修改任务；永久删除无法撤销。

## 安装与升级

- `Equora-v0.2.1-win-x64-Setup.exe`：可选择安装目录，适合大多数用户；使用与旧版相同的安装目录升级。
- `Equora-v0.2.1-win-x64.msix`：由 Windows 管理安装目录，版本号为 0.2.1.0，保持原包标识及签名证书以支持升级。
- 两种安装包均包含运行时和完整浏览器扩展。
- MSIX 首次安装需信任随附 `Equora-v0.2.1.cer` 公钥证书；已信任旧版证书无需重复导入。EXE 无需此步骤。

扩展请使用 `Equora-v0.2.1-BrowserExtension.zip` 覆盖原加载目录，再在 `edge://extensions` / `chrome://extensions` 重新加载扩展，并刷新旧拦截页及已打开的网站。保持原目录可保留扩展 ID 和临时允许的使用记录；更换目录后需在桌面端重新连接扩展 ID。

永久删除会删除关联的日历时间块、清单项和任务标签关联；保留专注历史并解除其任务关联。永久删除会清空当前任务撤销栈，避免撤销已不存在的任务。旧备份不会被修改。

附件附有 SHA256SUMS.txt，可核对完整性。
