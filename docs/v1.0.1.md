# Equora v1.0.1 — 正式版修复

修复 v1.0.0 中非 ASCII 文件路径(如中文文件名、中文目录)导致文件读写失败的问题。

## 修复内容

- 日历导入 ICS:文件路径包含中文或其他非 ASCII 字符时,报错「import_ics: cannot read ics file」且无法导入。现已修复,中文路径的 ICS 文件可直接导入。
- 同类修复一并覆盖:ICS 导出、任务 JSON/CSV 导入导出、备份创建/校验/恢复、日志文件初始化,以及数据库文件的打开。
- 解析侧保持对真实课程表导出文件的宽松处理:LF 行尾与 TAB 折行均可导入。

## 技术说明

原生层 C ABI 以 UTF-8 传递路径;Windows 的窄字符文件接口按 ANSI 代码页解释,两者编码不一致时,路径会被误读成不存在的文件。现所有入口统一把 UTF-8 路径转换为原生宽路径后再交给文件系统;SQLite 打开接口本身按 UTF-8 解释,转换保持一致。

## 验证

- 新增回归测试:中文目录下的 ICS 导入与导出(含 LF 行尾与 TAB 折行)。
- 原生核心 140 项、桌面应用 154 项、同步服务器 20 项及浏览器扩展 8 项测试全部通过,共 322 项。
- 使用真实课程表文件(249 个事件、中文文件名、LF 行尾与 TAB 折行)端到端验证导入成功。

## 安装与升级

- 推荐 `Equora-v1.0.1-win-x64-Setup.exe`,使用原安装目录覆盖安装即可,任务和数据不受影响。
- `Equora-v1.0.1-win-x64.msix` 版本为 1.0.1.0,沿用原包标识和签名证书。
- 两种安装包均包含运行时、原生组件和浏览器扩展;`SHA256SUMS.txt` 提供全部附件的完整性校验。
