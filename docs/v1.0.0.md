# Equora v1.0.0 — 正式版

v1.0.0 将学期安排、独立时间段和数据管理整合为完整的日常流程，保留本地优先、离线可用的使用方式。

## 学期安排与批量管理

- 按学期批量添加时，可勾选“同时添加到任务列表”。取消勾选后仅生成日历时间段，不增加任务列表条目。
- 时间段拥有独立标题，不创建任务也可填写、修改标题；标题与备注分别保存，ICS 导出保留标题。
- 右键时间段，选择“批量编辑时间段”或“批量删除时间段”。新建批次会列出同批次所有周次，支持勾选部分安排。
- 批量编辑可分别选择修改标题、备注、颜色和每天的起止时间；不勾选的字段及各自日期保持不变。可选择同步关联任务标题。
- 批量删除默认只移除日历安排，也可勾选将关联任务移入回收站。时间段删除无法撤销，任务可从回收站恢复。
- 批量编辑、删除及关联任务操作在同一数据库事务中执行；遇到过期版本或保存错误会整体回滚。
- v0.2.2 及更早版本没有批次标识，右键批量操作时列出已有时间段供手动选择，不按同名标题猜测分组。

## 学期自动归档

学期结束日期当天仍属于当前学期，次日起自动归档。程序关闭期间跨过结束日期的，会在下次启动时归档；运行期间也会检查日期变化。

设置中的“以往学期”保留学期名、起止日期，可直接打开该学期的日历。旧任务和时间段保持原样，新学期可重新填写并保存。关闭学期模式仍需二次确认。

## 清空数据

在“设置 → 数据与备份 → 清空数据…”操作，依次完成三次确认；最后一次必须输入“清空数据”。任何一步取消，都不会清空。

清空范围包括当前数据目录中的任务、时间段、专注记录、项目标签、限制规则、使用统计、偏好设置及学期归档。程序先停止写入、关闭数据库，再将原数据移至 `backups/before-reset-*` 恢复副本，随后退出；下次启动建立空白工作空间。正在专注时需先结束专注。

已有备份、日志、其他文件、数据目录位置和远端同步数据保留。这是重置本机工作空间，不是安全擦除；需要恢复时，退出程序后将恢复副本中的文件复制回原数据目录。

## 安装与升级

- 推荐 `Equora-v1.0.0-win-x64-Setup.exe`，使用原安装目录升级。
- `Equora-v1.0.0-win-x64.msix` 版本为 1.0.0.0，沿用原包标识和签名证书。
- 两种安装包均包含运行时、原生组件和浏览器扩展。数据库自动升级至 v7，保留原有数据。
- 原生接口升级至 C ABI v3，请使用完整安装包，不要混用旧版 DLL。
- 网站限制扩展另提供 `Equora-v1.0.0-BrowserExtension.zip`。覆盖原加载目录后，在浏览器扩展管理页重新加载。
- MSIX 首次安装需信任随附 `Equora-v1.0.0.cer`；已有证书仍然适用。自签名安装包可能显示 Windows 信任提示。
- `SHA256SUMS.txt` 提供全部附件的完整性校验。

官网功能介绍、用户指南、帮助中心及更新日志同步更新至 v1.0.0。
