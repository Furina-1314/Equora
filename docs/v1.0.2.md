# Equora v1.0.2 — 日历与使用限制更新

## 日历

- ICS 导入的普通日程现在可在周视图、日视图或议程中右键编辑标题、地点、备注和起止时间，也可确认后删除。
- 对 ICS 导入的重复日程，右键菜单明确标为“编辑整个重复日程”或“删除整个重复日程”。删除宿主日程后，后续重复实例不再出现在日历中。

## 应用与网站限制

- 命中进程限制时，在该程序窗口上显示封锁页。封锁页盖住标题栏以下的整个工作区，标题栏(含最小化、还原、关闭按钮)完整露出并可点击；封锁页的“关闭窗口”按钮发送同样的正常关闭指令。按钮为纯色扁平样式且悬停不变色，与扩展封锁页一致：关闭为红底白字、临时允许为浅灰底，用完后置灰。
- 封锁页持续覆盖命中窗口，不随焦点离开而消失，遮罩窗口通过系统窗口事件即时跟随窗口移动和缩放。窗口最小化时直接从任务栏隐藏，不留下可显示内容的预览缩略图；解除封锁或退出 Equora 时自动恢复显示，恢复后的窗口仍会被立即重新覆盖。
- 临时允许为每个应用一次、共 5 分钟，用完后按钮置灰，重启不重置。临时允许期间或有每日额度的应用，窗口右上角持续显示倒计时，不依赖该窗口是否在前台；到期后恢复限制。
- 专注时的分心应用提醒显示在当前应用窗口顶部正中，拖动窗口时逐帧跟随，视觉上与窗口一体；提醒只识别进程名，不读取窗口内容。
- 有每日使用额度的网站和进程，在活动窗口右上角显示剩余额度。剩余至少 10 分钟时按分钟显示，低于 10 分钟时按秒倒计时。网站额度由扩展和本地消息组件同步，约每 5 秒校准一次。
- 倒计时提示框会随 Windows 显示缩放和可用宽度调整，窄窗口中的文字可换行显示。

进程遮罩属于当前用户桌面的使用管理提示，不能阻止管理员权限程序、系统安全界面或后台服务。Equora 退出后不再显示遮罩；系统恢复工具保持白名单保护。

## 验证

原生核心 140 项、桌面应用 156 项、同步服务器 20 项及浏览器扩展 10 项测试通过，共 326 项。独立窗口验证了进程封锁页、临时允许、分心提醒及额度两档显示；浏览器倒计时提示在 240、320、390 像素宽度下检查了内容完整性。

## 安装

推荐从 [最新正式版](https://github.com/Furina-1314/Equora/releases/latest) 下载 `Equora-v1.0.2-win-x64-Setup.exe`；MSIX 为 1.0.2.0，沿用包标识和签名证书。网站倒计时功能需更新扩展文件并在 Edge 或 Chrome 的扩展管理页重新加载。安装包附 SHA256SUMS.txt。
