# Equora v1.1.0 — 桌面小组件与日历体验

## 桌面小组件

- 新增 Windows 7 桌面小工具式的两个小组件,在“设置 → 桌面小组件”中开关;随应用启动自动恢复,关闭小窗即停用。
- 小组件钉在桌面层:位于壁纸与桌面图标之上、普通窗口之下,不占任务栏与 Alt+Tab;按 Win+D“显示桌面”即可看到。头部整条可按住拖动,右上角 ✕ 关闭。
- **任务小组件**:列出未完成任务(按截止时间排序,最多 50 项),打勾即完成任务,与任务页打勾一致;每 30 秒自动刷新,也可手动刷新。
- **日历小组件**:显示日程,支持日视图、周视图和议程三种视图,可与主窗口独立切换;提供上一时段、今天、下一时段导航,冲突日程以红色标出。

## 日历改进

- 日历页中的“时间段”统一改称“日程”:新建、编辑、批量编辑、批量删除与右键菜单等全部入口使用同一称呼,不再区分两种说法。
- 新建日程(含按学期批量添加)的颜色输入框右侧新增预览方块:方角、无边框、高度与文本框一致,实时反映输入的色号;点击方块弹出选色表,在选色表中选色自动回填色号。
- 设置页自定义主题色的预览方块同样实时反映输入色号,并可点击打开选色表。
- 批量编辑与批量删除日程改为复选框打勾表示选中,可逐项切换,支持全选/取消全选,已选数量实时显示。

## 验证

原生核心 140 项、桌面应用 159 项、同步服务器 20 项及浏览器扩展 10 项测试通过,共 329 项。真实窗口冒烟验证:两个小组件按偏好自动恢复打开、内容正常渲染、偏好状态正确记录;封锁页遮罩行为无回归。

## 安装与升级

- 推荐 `Equora-v1.1.0-win-x64-Setup.exe`,使用原安装目录覆盖安装即可,任务和数据不受影响。
- `Equora-v1.1.0-win-x64.msix` 版本为 1.1.0.0,沿用原包标识和签名证书。
- `SHA256SUMS.txt` 提供全部附件的完整性校验。
